# Правила проекта
- Структура: godot/ — игра (godot/tests — тесты), docs/ — документация и память (MEMORY.md), docs/chat/ — история диалога с ботом.
- Проект пока пустой: база под новый проект. Стек и команды запуска добавить, когда появятся.
- Стек: Godot 4.3 (GDScript, GL Compatibility, экспорт Web) в godot/. Тесты логики: godot --headless --path godot -s tests/run.gd (CI: godot.yml).
- Обязательно: каждая сессия заканчивается публикацией — коммит и push в основную ветку (main), потому что push в main запускает godot.yml и выкладывает сборку на Pages. Не запушено = не сделано. Защита main — ветка claude/answer-<Запрос>, сказать об этом в ответе.
- Структура кода: world.gd — только сборка сцены и цикл; заклинания — spells.gd, постобработка — postfx.gd, герой — hero.gd, уровень — level.gd, свет — lighting.gd, правила — game.gd.
- После каждого внесения изменений — повторный рефакторинг и оптимизация добавленного (убрать дубли, лишние вычисления, мёртвый код), тесты прогнать снова, затем публикация. (владелец, 2026-10-26)
