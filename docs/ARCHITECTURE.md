# Архитектура

Приложение «Покупки» — PWA (Android ставит как обычное приложение). Без сервера и сборки.

Слои (app/):
• store.js — чистая логика: список, дубли, ссылка-кодировка, сопоставление отсканированного товара со списком (тесты)
• lookup.js — название и категория по штрихкоду из Open Food Facts (бесплатно, без ключа)
• scan.js — камера и BarcodeDetector (Chrome на Android); без него — ручной ввод кода
• app.js — интерфейс; index.html, style.css; sw.js — офлайн; manifest + icons — установка

Сценарии:
1. Сканировать товар → поиск названия → в список. Неизвестный код — спросит название. Удаление кнопкой ✕.
2. Поделиться: список кодируется в ссылку (#l=…), отправка через меню «Поделиться» Android. Получатель открывает ссылку — список добавляется к его.
3. В магазине: код совпал → «Нужный продукт, готово ✓», галочка. Нет совпадения, но та же категория или общее слово названия → «Похожий продукт, заменить?».

Данные: localStorage, ключ products.v1. Это копия списка по ссылке, не общий онлайн-список.

Запуск: npm start (http://localhost:8080), тесты npm test. Камера работает только по HTTPS (или localhost): нужен хостинг, напр. GitHub Pages (папка app/); публикация не включена — нужно слово владельца.
