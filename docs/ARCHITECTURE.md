# Архитектура

Приложение «Задачи» — PWA (веб-приложение, которое Android ставит как обычное).

Выбор: PWA вместо нативного приложения. Нет сборки, Android Studio, подписи ключами и аккаунта Google Play; обновление — просто выкладка файлов. Минус: нет доступа к части возможностей телефона. Если понадобится APK — обернуть то же приложение через Capacitor или Bubblewrap (TWA), код менять не придётся.

Слои (app/):
• store.js — чистая логика задач и хранение (без браузера, покрыта тестами)
• app.js — интерфейс: отрисовка, события, кнопка установки
• index.html, style.css — разметка и тема (светлая/тёмная)
• sw.js — service worker: кэш оболочки, работа офлайн
• manifest.webmanifest + icons/ — данные для установки на Android

Данные: localStorage на устройстве, ключ tasks.v1. Сервера нет.

Дальше: синхронизация между устройствами (бэкенд или Cloudflare Worker + KV), напоминания, экспорт.

Запуск локально: npm start, открыть http://localhost:8080. Тесты: npm test.

Установка на Android: открыть адрес приложения в Chrome по HTTPS → меню → «Установить приложение» (или кнопка в самом приложении). Нужен хостинг по HTTPS, например GitHub Pages (папка app/). Публикация не включена: нужно слово владельца.
