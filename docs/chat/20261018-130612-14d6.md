## Ответ
Open Food Facts — открытая бесплатная база продуктов, ключ не нужен.

Приложение запрашивает у неё название и категорию товара по штрихкоду. Категория нужна для режима «В магазине»: по ней предлагается замена похожего товара. Если кода в базе нет, приложение спросит название вручную.

Оговорка: реальный запрос к Open Food Facts я пока не проверял — в песочнице нет сети. Работает только по тестам с подменой.
