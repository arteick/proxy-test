## Ответ
Python + SQL + реляционные БД на международном рынке востребованы, но как база, а не как отдельная профессия. Надёжной статистики по странам я не нашёл, цифры ниже ориентировочные (блоги и рекрутеры, не проверено).

Куда ведут эти навыки:
• Data engineer: SQL есть почти в каждой вакансии; в анализе 1839 удалённых вакансий Python на 1 месте (1377), SQL на 2 (1307), больше всего senior-позиций.
• Analytics engineer: SQL, моделирование, тесты, Git; роль всё чаще встречается в вакансиях 2026.
• Database reliability engineer (DBRE): БД плюс автоматизация и мониторинг; ближе всего к вашему опыту, но с дежурствами.
• Backend/Python developer: БД как часть стека.

Зарплаты (США, база в год):
• data engineer: около 80–180 тыс. USD, mid 119–149, senior 147–179;
• удалённо: 110–170 тыс., senior выше 200 тыс.;
• официальный ориентир BLS для администратора БД: 104 620 USD.

Для удалёнки из другой страны компании часто берут 80–120% от базы по локации.
