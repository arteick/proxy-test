Что такое GitHub Page?

## Ответ
GitHub Pages — бесплатный хостинг статических сайтов прямо из репозитория GitHub.

Как это работает: вы включаете Pages в настройках репозитория, выбираете ветку или папку (например main и /docs), и GitHub отдаёт HTML, CSS и JS по адресу https://<имя>.github.io/<репозиторий>/ с HTTPS.

Подходит для сайтов-визиток, документации, PWA. Серверного кода (баз, PHP, Node) нет, только статика; сайт публичный, даже если репозиторий приватный (на платных планах доступ можно ограничить).

Для вашего приложения «Покупки» это самый простой способ получить HTTPS, нужный для камеры. Включить Pages я не могу без вашего слова. Включить?
