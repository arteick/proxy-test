## Ответ
Точной цены API Национального каталога не нашёл, но по сути: сам доступ к API отдельно не продаётся, он идёт с регистрацией в Честном ЗНАКе.

Что известно:
• Регистрация участника оборота и личный кабинет бесплатны, но нужны ИНН и электронная подпись (КЭП или МЧД). Подпись обычно платная (от нескольких тысяч ₽ в год).
• Чтение карточек товаров в Национальном каталоге бесплатно, без отдельной платы за запросы. Это моё допущение из сторонних статей, официальных тарифов не нашёл.
• Для физлица без ИП или юрлица доступа, скорее всего, нет.
• Есть лимиты на частоту запросов, точные цифры в документации.
• Карточки заполняют производители, поэтому покрытие у обычных продуктов неполное.

Итог: платить за API не придётся, но нужны ИП/юрлицо и подпись. Официальный портал не открыть из песочницы, проверьте условия на честныйзнак.рф.
