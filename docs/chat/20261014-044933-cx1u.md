## Ответ
Да, подключение проектов предусмотрено (этап 3, почти всё готово). Правки claude-proxy отсюда — нет.

Как подключить claude-proxy как проект:
1. claude.ai/code/routines → New routine, название claude (код проекта), Instructions — «Типовой Instructions» из docs/NEW_PROJECT.md.
2. Репозитории: сначала arteick/claude-proxy, затем он же второй раз не нужен — регламент читается из него же. Окружение claude-proxy, триггер Call via API, Generate token.
3. В боте: /new claude arteick/claude-proxy trig_… , затем /token claude <токен>.
4. Переключение между проектами — кнопками или /use.

Что можно править отсюда: сессия этого проекта видит claude-proxy только для чтения (регламент, раздел 6), менять и пушить туда нельзя. Править можно только proxy-test.

Чтобы править сам мост, подключите его как отдельный проект по шагам выше — тогда сессия будет работать в его репозитории и подхватит его CLAUDE.md (тесты, правила). Оговорка: пункт 3.3 (авторазметка docs/ при подключении) ещё не сделан, и деплой Worker запускается workflow Deploy.
