## Ответ
Коротко: Claude Code сам картинки не рисует, графику лучше делать в отдельном сервисе, а код, сюжет и сборку — в Claude Code.

Что Claude Code умеет:
• писать всю игру: движок (Ren'Py — самый простой для новелл, или Godot), сцены, диалоги, меню, сохранения;
• писать сценарий, ветвления, имена и описания персонажей, промпты для генерации картинок;
• смотреть на ваши референсы и описывать стиль, проверять, как картинки встали в игру;
• рисовать простые векторные вещи (SVG), заглушки, UI;
• вызывать API генерации картинок скриптом, если вы дадите ключ.

Чего не умеет: рисовать арт по референсам как Midjourney, ChatGPT/GPT-image, Flux или Stable Diffusion. Для этого берите их, а готовые файлы кладите в репозиторий.

Важно для Стима: платный взнос за приложение (около 100 долларов), и при публикации надо раскрыть использование ИИ-контента. Проверьте актуальные правила на partner.steamgames.com. Единый стиль персонажей — самое трудное, для него хорошо подходят Stable Diffusion с LoRA или сервисы с загрузкой референсов.
