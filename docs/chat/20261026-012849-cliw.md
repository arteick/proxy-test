## Вы
А добавь мне ещё поддержку всех горячих клавиш самых используемых

## Время
Отправлено: 2026-10-26T01:28:49.000Z; старт: 01:29:02; готово: 01:40:00

## Ответ
Готово: в редакторе работают самые частые горячие клавиши, как в VS Code.

• Выделение: Shift+стрелки, Ctrl+A, Ctrl+L, Ctrl+D (следующее вхождение), двойной/тройной клик, мышью
• Навигация: Home/End, Ctrl+←/→, Ctrl+Home/End, PgUp/PgDn
• Правка: Ctrl+Z / Ctrl+Y, Ctrl+C/X/V, Tab / Shift+Tab, Ctrl+/ (комментарий), Ctrl+Backspace/Delete
• Строки: Alt+↑/↓ (сдвиг), Shift+Alt+↑/↓ (дубль), Ctrl+Shift+K (удалить), Ctrl+Enter (новая строка)

Допустил: комментарий всегда «//», Ctrl+S просто сохраняет (автосохранение уже есть). Поиска Ctrl+F пока нет — в ROADMAP.

Изменено: ядро и интерфейс редактора, подсказка, тесты, память.
Проверки: npm test — 23 теста зелёные; в браузере (Playwright) проверены комментарий, отмена, сдвиг и удаление строки, удаление слова. Буфер обмена в headless-браузере не проверить.
