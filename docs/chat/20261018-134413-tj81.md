## Ответ
Через Честный ЗНАК напрямую из приложения добавлять не выйдет, но есть два пути.

Что нашёл: карточки товаров лежат в Национальном каталоге (часть Честного ЗНАКа). API отдаёт данные по GTIN (штрихкоду), но нужен личный кабинет с ИНН и электронная подпись (КЭП или МЧД). Ключ в браузерное приложение класть нельзя, значит нужен свой сервер-посредник. Публичного бесплатного поиска по штрихкоду без регистрации не нашёл.

Варианты:
1. Свой небольшой сервер (Cloudflare Worker), который ходит в API Национального каталога по вашему ключу, а приложение спрашивает его после Open Food Facts. Нужна ваша регистрация и ключ.
2. Сканировать код маркировки (DataMatrix) на упаковке: из него достаётся GTIN, а название всё равно придётся искать в базе. Сам по себе он название не даёт.

Допущение: условия API проверил только по сторонним статьям, официальную документацию из песочницы не открыть. Код не менял.

Источники: https://selsup.ru/blog/rabota-s-api-v-chestnogo-znake/ и https://infostart.ru/1c/tools/2216949

Хотите вариант 1? Если да, нужен ключ API Национального каталога.
