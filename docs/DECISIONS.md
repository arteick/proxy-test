# DECISIONS

## 2026-10-26 Three.js или Godot для ASCII-игры
Выбрано (рекомендация, владелец не утверждал): Three.js (веб) как основной путь; Godot — если нужна полноценная игра (физика, сцены, экспорт в десктоп/мобайл).
Почему: веб — ссылка открывается сразу, GitHub Pages уже настроен, ASCII-шейдер готов. Godot сильнее по движку и редактору, но веб-экспорт тяжелее, и тут нужен ручной редактор.

## 2026-10-26 Переход на Godot (решение владельца)
Выбрано: Godot 4.3, рендерер GL Compatibility (нужен для веб-экспорта), код на GDScript, сцена собирается кодом (world.gd), ASCII — spatial-шейдер на полноэкранном квадре перед камерой (screen+depth texture), атлас символов рисуется в SubViewport.
Варианты: C# (.NET) — веб-экспорт Godot 4 не поддерживает; Forward+ — не работает в вебе. Тесты логики — headless-скрипт без плагинов. Сборка и веб-экспорт — GitHub Actions (образ barichello/godot-ci), Godot локально не нужен.
Старый веб-прототип (src/, Three.js) остаётся, пока Godot-версия не проверена глазами.

## 2026-10-26 Без class_name в скриптах Godot
Выбрано: подключать скрипты через const X = preload("res://...") вместо class_name. Почему: в CI нет импорт-кэша (.godot), глобальные классы не находятся при запуске -s. Коллизии героя — свой круговой push-out (move.gd), а не физика: проще тестировать headless.

## 2026-10-26 Что за MVP
Выбрано: «Кристаллы и тени» — сбор 8 кристаллов, 3 преследующие тени, 3 жизни, без таймера. Варианты: выживание на время, платформер. Почему: использует уже готовые колоннаду, свет и героя; цель понятна за секунду; свет кристаллов красиво читается в ASCII. Правила отделены от сцены (game.gd) ради headless-тестов.

## 2026-10-26 Автопубликация Godot-сборки
Выбрано: godot.yml после тестов и экспорта сам деплоит build/web на GitHub Pages при каждом пуше в main (godot/, src/); старый прототип лежит в /old/. pages.yml теперь только ручной (иначе затирал бы Godot-сборку). Почему: владелец хочет видеть изменения сразу по ссылке. Thread-поддержка выключена, так что заголовки COOP/COEP не нужны.

## 2026-10-26 Удаление старого прототипа
Выбрано: удалить src/ (Three.js), tests/ascii.test.js, package.json, pages.yml и копирование в /old/. Почему: владелец не нужен прототип, Godot-версия его не использует (проверено поиском). Остаётся в истории git.

## 2026-10-26 Свет важнее шейдера
Выбрано: красоту ASCII-картинки чинить через освещение сцены (hemisphere-ambient, затухание, тон-маппинг), а не через движок. Варианты: вернуться на Three.js. Почему: в Three.js-прототипе была та же схема ASCII, разница в свете (см. ROADMAP). Код пока не менялся.

- 2026-10-26: клавиши управления — физические (physical_keycode), чтобы работали в любой раскладке.

- 2026-10-26: «двумерность» — ортографическая камера вместо перспективной (вариант: просто круче наклон) — масштаб одинаков по экрану, ближе к 2D. Читаемость вдали — масштабирование значков и режим плоских цветов, а не затухание по дистанции (в ортографии дистанция не растёт).
