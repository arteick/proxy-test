# Решения
- 2026-10-26 Редактор: свой рендер строк + скрытый textarea для ввода, а не Monaco/CodeMirror. Варианты: Monaco (тяжёлый, нужен CDN/сборка), CodeMirror (зависимость). Выбрано своё — ноль зависимостей, мультикурсор прост в модели (курсоры = смещения, правки применяются разом).
- Хранение: localStorage браузера (MVP, без сервера).
- 2026-10-26 Хостинг: GitHub Pages через Actions (deploy-pages), публикуется папка src/. Варианты: Pages из ветки (нужна папка /docs или корень, пришлось бы двигать src), Actions (src остаётся на месте, тесты перед деплоем). Выбран Actions.
- 2026-10-26: старый проект на Pages — вероятные причины: кэш браузера/CDN (до ~10 мин) и service worker «Покупок» (sw.js). Добавлен src/sw.js, который сам удаляется и чистит кэши, плюс отписка в index.html.
- 2026-10-26 Горячие клавиши: набор VS Code, выделения хранятся как anchors рядом с cursors (совместимо со старым API). Undo — стек состояний в app.js, набор символов подряд сливается в один шаг. Комментарий всегда «//» (язык не определяется). Копирование через navigator.clipboard, вставка — через событие input.
